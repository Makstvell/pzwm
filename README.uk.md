# pzwm

**Wayland-композитор з нескінченним полотном, написаний на Rust.** Вікна
лежать на безкінечному полотні, яке можна рухати й масштабувати як у
дизайнерській програмі: затисни колесо миші й тягни, крути колесо — зум
навколо курсора, віддали — і бачиш усе одразу.

## Можливості

- **Нескінченне полотно** із сіткою з точок, яка лишається читабельною на
  будь-якому зумі (крок підлаштовується, як у Figma).
- **Рух як у дизайнері**: затисни середню кнопку (колесо) і тягни — і по
  порожньому місцю, і **над вікнами**. Звичайний клік середньою кнопкою все
  одно доходить до програми (вставка, відкрити посилання у новій вкладці).
  Тягнути лівою по порожньому полотну теж можна.
- **Зум до курсора**: колесо над порожнім місцем або `Super+колесо` будь-де,
  і над вікнами теж; щипок на тачпаді; свайп трьома пальцями — рух. Скрол,
  що почався на порожньому полотні, не «застрягає», коли під курсор
  під'їжджає вікно.
- **Міні-карта** в куті екрана: усі вікна воркспейсу й видима область.
  Клік по вікну — перейти до нього, клік або перетягування — посунути вид
  (`Super+M` ховає/показує).
- **Біндинги миші в конфігу** (`[mouse]`): рух, зум, переміщення й розмір з
  будь-яким модифікатором і кнопкою чи скролом.
- **Без «важкості»**: короткі анімації (110–130 мс) без інерції.
- **Розгорнути / на весь екран і назад**: вікно повертається рівно туди, де
  було на полотні, з тим самим розміром.
- **Рухати, розтягувати, закріплювати, прилипання**: тягни за заголовок або
  `Super+Shift+мишка` (з `titlebar_drag = false` вікна рухаються лише так);
  розтягування за широкі зони країв і кутів або `Super+права`; магнітні краї між вікнами;
  кинь вікно до лівого/правого краю екрана — займе половину (верхній край —
  розгорнути); **закріпи** вікно на екрані — полотно рухатиметься під ним.
- **Дизайн**: заокруглені кути (вміст теж обрізається), градієнтна рамка в
  активного вікна, м'які тіні, тонкий заголовок з кнопками закрити /
  розгорнути / закріпити. Програми з власним заголовком (GTK4) лишають свій.
- **Твій бар працює**: wlr-layer-shell, тож waybar, DankMaterialShell, rofi,
  mako, swaync, awww/swaybg — усе працює. Сервіси systemd, прив'язані до
  `graphical-session.target`, стартують самі.
- Блокування екрана (hyprlock, DMS), idle (hypridle), буфер обміну
  (cliphist), скріншоти (grim, slurp), дробове масштабування, захоплення
  миші в іграх, кілька моніторів і ноутбуки з двома GPU, 10 воркспейсів зі
  своєю камерою.
- X11-програми через [xwayland-satellite](https://github.com/Supreeeme/xwayland-satellite), якщо він встановлений.
- **Пошук** (`Super+/`): вікна, групи й закладки за назвою, камера летить
  туди. Список показує rofi, fuzzel або wofi.
- **Історія камери**: `Super+,` / `Super+.` — назад / вперед по стрибках
  (fit, пошук, огляд, закладка, клік на міні-карті), як у браузері.
- **Закладки камери**: `Super+Alt+Shift+1…5` запам'ятати вид,
  `Super+Alt+1…5` полетіти туди.
- **Групи**: вікна, що належать разом, отримують кольорову рамку; групу
  можна показати цілою, рухати й згортати одним рухом.
- **Скретчпад**: випадний термінал на ``Super+` ``.
- **Правила вікон** (`[[rule]]`): воркспейс, місце, розмір, закріплення,
  розгортання, група для конкретної програми.
- Таскбари й доки бачать і керують вікнами (foreign-toplevel); kanshi,
  wdisplays і wlr-randr міняють монітори наживо; нічний режим через
  wlsunset / gammastep; методи вводу (fcitx5) і графічні планшети.

## Встановлення

Потрібен Rust ≥ 1.85 і стандартні бібліотеки для Wayland-композиторів.

```sh
git clone https://github.com/Makstvell/pzwm
cd pzwm
./install.sh --deps   # поставить пакети (Arch, Fedora, Debian/Ubuntu, openSUSE, Void), збере і встановить
# або, якщо бібліотеки вже є:
./install.sh
```

Скрипт збирає release-версію і через `sudo` кладе `pzwm` і `pzwm-session` у
`/usr/local/bin`, сесію в `/usr/share/wayland-sessions/pzwm.desktop`,
`pzwm-session.target` для systemd і налаштування порталів. Конфіг з усіма
коментарями копіюється в `~/.config/pzwm/config.toml` (твій ніколи не
перезаписується). Видалити: `./install.sh --uninstall`.

Варто доставити: `xwayland-satellite grim slurp wl-clipboard xdg-desktop-portal-gtk`.

### Спробувати без виходу з сесії

```sh
pzwm --nested
```

### Запуск

Вийди з сесії й обери **pzwm** на екрані входу, або запусти `pzwm-session`
з TTY. Попередня сесія (Hyprland тощо) нікуди не дівається. Логи:
`journalctl --user -t pzwm -b`.

## Налаштування

`~/.config/pzwm/config.toml`; усі опції описані в
[`resources/default-config.toml`](resources/default-config.toml). Перевірка:
`pzwm --check-config`. Зміни застосовуються одразу після збереження файлу
(або `pzwm reload`); якщо в конфігу помилка — лишається старий і приходить
сповіщення. Команди для скриптів і бару: `pzwm msg workspace 3`,
`pzwm msg overview`, `pzwm msg windows`.

- `[general] scale = 1.5` — масштаб (DPI) для всіх моніторів; окремий монітор
  перевизначається через `[[output]] scale`. Назви моніторів — у лозі.
- `[mouse]` — біндинги миші, `"Super+Shift+left" = "move-window"` тощо.
- `[minimap]` — міні-карта з живими прев'ю вікон: `enabled`, `position` (`cursor` — викликається `Super+M` біля курсора; або кут екрана), `width`, `popup_width`, кольори.
- Нові вікна відкриваються на 90 % × 90 % екрана: `[canvas] new_window_width`,
  `new_window_height`. Діалоги й вікна фіксованого розміру — як є.
- Дзеркало монітора: `[[output]] name = "HDMI-A-1"` + `mirror = "eDP-1"`.
  Дзеркало масштабується на весь екран телевізора, разом зі шпалерами.
- Паралакс шпалер: `[parallax] enabled = true` — фон повільно й плавно
  гойдається вліво-вправо і трохи зсувається проти камери, коли рухаєш
  полотно. `strength` — наскільки далеко (частка ширини екрана, 0.01–0.15),
  `period` — секунд на одне повне гойдання, `follow_camera` — реагувати на
  рух полотна. Шпалера трохи збільшена, тож краї ніколи не видно.
- Відео в Chrome/Chromium на весь екран більше не згортається через ~1.5 с:
  pzwm тепер повідомляє програмам, що кадр показано (presentation feedback).
- Профілі робочого столу: `pzwm msg profile save work` / `profile load work` /
  `profile list` (або біндинг `"Super+F1" = "profile save work"`). Завантаження
  повертає вікна на місця й запускає програми, яких бракує. Файли — у
  `~/.local/state/pzwm/profiles/`.
- Бар DMS показує воркспейси pzwm (через протокол Umbriel, `UMBRIEL_SOCKET`).
- Правила вікон:
  ```toml
  [[rule]]
  app_id = "pavucontrol"   # або title = "*Picture*"; * і ? як у shell
  size = "700x500"
  pin = true
  ```
  Ще є `workspace`, `position = "x,y"`, `maximize`, `fullscreen`,
  `group`, `scratchpad`.
- `[scratchpad] command` — що запускати (за замовчуванням foot; для ghostty:
  `ghostty --class=pzwm-scratchpad`). `[general] picker` — свій
  dmenu-пікер для пошуку.
- Налаштування моніторів застосовуються одразу після збереження конфігу;
  зміни від kanshi / wdisplays діють до наступного перечитування конфігу.
- **Display Settings** у лаунчері (або `pzwm-config --page monitors`) —
  сторінка моніторів pzwm config: підключені монітори з поточним режимом,
  вибір роздільності й частоти зі списку того, що вміє монітор, масштаб,
  позиція, дзеркало. `nwg-displays` під pzwm не працює: він уміє лише
  sway, Hyprland, niri і Mango через їхні власні IPC. Працюють wdisplays,
  wlr-randr, kanshi.
- Скрипти: `pzwm msg windows --json`, `outputs --json`, а
  `pzwm msg subscribe` друкує JSON-події (відкрилося / закрилося /
  змінилося вікно, фокус, воркспейс), по одній на рядок.
- Схожі проєкти: [docs/similar-projects.md](docs/similar-projects.md).
- Якщо DMS-бар не з'являється, бо сервіс увімкнений лише для Hyprland:
  `systemctl --user add-wants pzwm-session.target dms.service`.
